Guia de Desenvolvimento Web

1. Fundamentos do Front-End

O front-end é a parte visual e interativa de um site ou aplicação web.

1.1. Estrutura com HTML5

Responsável por organizar o conteúdo semântico da página, como textos, imagens e links.

1.1.1. Boas práticas de semântica

Usar tags corretas facilita a leitura por buscadores e leitores de tela.

Exemplo de uso correto

Nunca escolha uma tag de título apenas pelo tamanho da letra; para mudar o visual, usa-se CSS.

Nota técnica sobre SEO

Mecanismos de busca usam a ordem lógica de h1 a h6 para entender a relevância de cada assunto.

2. Estilização e Layout

Depois de estruturar o conteúdo, aplicamos cores, fontes e posicionamento na tela.

2.1. Introdução ao CSS

Permite separar completamente a estrutura do documento da sua aparência visual
